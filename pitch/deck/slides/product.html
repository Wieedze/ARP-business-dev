THE FIRST PRODUCT

Is it me, or is the tool broken for everyone?

A free dashboard for the developer who installs the hook. It compares each tool’s success for their agent with every other agent on ARP, and warns when a tool breaks or changes.

$ arp status

tool you others verdict

github-mcp 99% 99% changed

postgres-mcp 61% 98% only you

weather-x402 44% 46% broken everywhere

filesystem 100% 100% ok

others switched to: open-meteo

Example output. Private data stays on the machine; only “agent uses tool, and it works” goes public.

Why developers install it: it answers a question nothing else answers, because tracing tools only see one agent. Why it feeds ARP: every install produces public usage records as a side effect.
