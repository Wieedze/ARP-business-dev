HOW IT WORKS

Is it me, or is the tool broken for everyone?

1 · Install. One command, or a plugin for Claude Code and Gemini.

2 · Record. A hook logs each call’s outcome on the machine. Never the content.

3 · Publish. When the agent brings a proof, ARP sponsors its deposit on Intuition. The agent owns the position.

Example output. ARP is the directory and the verifier, never the relay: no request or prompt passes through ARP.

Built on testnet: the CLI with one arp binary, the hook, the MCP server, the probe, and the Claude Code and Gemini plugins. The free view is why developers install it; every install produces public usage records. Proof levels: a payment plus a signed hire receipt is strong; the hook alone is weak and stays labelled declared.
