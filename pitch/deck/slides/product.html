HOW IT WORKS

Is it me, or is the tool broken for everyone?

1 · Record. A hook logs each tool call on the machine. Never the content.

2 · Declare. The first call that works writes “agent uses tool” on Intuition.

3 · Compare. The developer sees their tools next to every other agent’s.

$ arp status

tool you others verdict

github-mcp 99% 99% changed

postgres-mcp 61% 98% only you

weather-x402 44% 46% broken everywhere

filesystem 100% 100% ok

others switched to: open-meteo

Example output. ARP holds no key, sits in no request path and composes no score; a tool’s place comes from what others put behind it.

The free dashboard is why developers install it: tracing tools only see one agent, ARP sees the network. Every install produces public usage records as a side effect.
