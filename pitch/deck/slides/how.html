HOW IT WORKS

Record, declare, read.

01

Record

A hook in the agent runtime logs each tool call on the machine: tool, success, time. Never the content.

02

Declare

The first call that works writes “agent uses tool” on Intuition, signed by the agent, for a fee that does not come back.

03

Read

Search by need. Places in the answer come from what others put behind a tool, not from its own deposits.

ARP holds no key, sits in no request path, and composes no score. Unplug it and every record is still on the graph.

Three steps. The hook records locally. The first successful use becomes a public, paid, attributed claim on Intuition. Readers search by need, and a tool's place comes from third parties: self-deposits count for much less, which is what keeps it from being an ad auction.
