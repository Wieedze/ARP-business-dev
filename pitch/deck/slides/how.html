HOW IT WORKS

Four steps. You do the first one.

1 · ASK

You describe the task, in your own words.

2 · FIND

Claude searches ARP by the need: 663 skills and 53 tools on testnet.

3 · USE

ARP serves the skill’s instructions, with a signed receipt.

4 · RECORD

The use is declared, public and attributed. The next agent sees it.

No GitHub, no skills.sh, no wallet on screen. A plugin for Claude Code, an extension for Claude Desktop.

ARP is the directory and the verifier, never the relay: no prompt and no request passes through ARP.
