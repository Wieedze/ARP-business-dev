# Pitch

The living versions are the Claude artifacts "ARP Pitch Deck" (14 slides, English) and "ARP : kit de présentation" (French, with English copy). This folder keeps the deck's slide sources under version control.

## The lines

| | |
| --- | --- |
| Goal | ARP makes money flow to the tools agents actually use. |
| Signature | Stars show who looked. ARP shows who used it. |
| Vision | Money follows usage. |
| Mission | Keep an open record of what agents actually use, and whether it works. |
| What ARP sells (ADR 0075) | The place in the answer, and your place comes from others. |
| How money moves (ADR 0076) | ARP plans payments and never holds one. |

## 10 seconds

> Half the tools AI agents can call don't work, and nobody can tell which. ARP records what agents actually use, and whether it worked, so agents pick tools that work and money flows to them.

## Words never used

`best`, `score`, `verified` about a usage, `proof`, `trustless`, `guaranteed`. The category is **public usage record**, not "proof of use".

## Deck order

cover, problem, signals, insight, how, product, whynow, landscape, model, gtm, plan, founder, vision, ask.
