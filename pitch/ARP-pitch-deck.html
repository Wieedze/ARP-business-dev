THE IDEA

Stars show who looked.
ARP shows who used it.

Each tool call that works, recorded by the agent that made it, on an open graph anyone can read.

This is the whole idea. Usage is the signal, because it is the one thing a tool cannot fake on its own: another agent has to call it, and the call has to work.

HOW IT WORKS

Is it me, or is the tool broken for everyone?

1 · Record. A hook logs each tool call on the machine. Never the content.

2 · Declare. The first call that works writes “agent uses tool” on Intuition.

3 · Compare. The developer sees their tools next to every other agent’s.

$ arp status

Example output. ARP holds no key, sits in no request path and composes no score; a tool’s place comes from what others put behind it.

The free dashboard is why developers install it: tracing tools only see one agent, ARP sees the network. Every install produces public usage records as a side effect.

BUSINESS MODEL

The rated party pays, never the reader.

NOW

Grants

Ecosystem grants pay the first declaration fees.

NEXT

Place in the answer

Tool authors and operators pay for visibility and a badge.

THEN

Pay per check

Agents pay cents over x402 to check a tool before calling it.

GOAL

Money follows usage

Grants and agent earnings routed to the tools agents used.

Precedent: on review platforms the rated business pays, and readers never do (Trustpilot, $261M revenue in 2025). ARP plans payments and never holds one.

Readers never pay for ratings in any adjacent market. Money comes from the rated party buying visibility, or from a score that gates money. ARP starts with grants, then sells the place in the answer, then pay-per-check, and the end state is routing value to the tools that agents depend on.
